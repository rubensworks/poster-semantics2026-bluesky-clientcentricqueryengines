From Server-centric to Client-centric Data Integration
over Decentralized Knowledge Graphs with Personal Query Engines

Ruben Taelman

Department of Electronics and Information Systems, Ghent University – imec · Research Foundation – Flanders (FWO)

The opportunity

Decentralized Knowledge Graphs (DKGs) let people and organizations keep control of their data while still interlinking it across boundaries.

Today, integration is mostly server-centric: data is copied into cloud systems that users cannot inspect or control.

Mindset shift: reusable personal query engines on the user's device integrate data close to the user—controlled, transparent, and private by design.

Client-centric data integration

Personal query engines separate where data is stored from where it is integrated.

01

Heterogeneous data sources

How can an engine discover and query sources whose interfaces are unknown and different?

Objectives

  • 1a · Discover capabilities
    Declarative hypermedia query shapes remove prior assumptions.
  • 1b · Plan adaptively
    Use authority over shapes and larger subqueries during execution.
  • 1c · Prune links
    Reduce traversal through early-completing authoritative joins.
02

Personalized processing

How can users decide how their query engine should search, rank, and explain?

Objectives

  • 2a · Represent preferences
    Compose explicit, implicit, trust, and operational preferences.
  • 2b · Use preferences
    Drive focused traversal and expose how- and where-provenance.
  • 2c · Learn patterns
    Cache and prefetch based on recurring user query patterns.
03

Context-aware optimization

How can client-driven processing meet interactive performance goals?

Objectives

  • 3a · Adapt to resources
    Optimize speed, battery, CPU, latency, and bandwidth together.
  • 3b · Reuse executions
    Rewrite queries using federated materialized RDF views.
  • 3c · Outsource privately
    Decompose queries across privacy-preserving and public parties.

Impact

Client-centric integration enables performant querying without prior source knowledge, preference-specific optimization, and resource-aware privacy-preserving computation—supporting healthcare, social media, personal genomics, and other decentralized applications.
